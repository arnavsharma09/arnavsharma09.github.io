RetainIQ github.com/arnavsharma09/RetainIQ →
PostgreSQL · SQL · Python (scipy, statsmodels) · Power BI · Docker

An end-to-end analytics pipeline on 99,441 orders across 9 relational tables, modeled as a star schema with quintile-scored RFM segmentation across ~95K customers into 7 value tiers. A controlled hypothesis test isolated delivery time's effect on satisfaction independent of distance — Shapiro-Wilk confirmed non-normality, so Mann-Whitney U was used as the pre-committed primary test. Findings were shipped as a 6-visual interactive Power BI dashboard with 5 stakeholder-ready recommendations.

4.31 vs 3.75 rating, p<0.001 3.04% repeat-purchase rate 62.5% revenue in 3/27 states
